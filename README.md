# HumanGL_matrix

An educational project about hierarchical modeling, custom matrix transformations,
and a matrix stack, used to animate an articulated person with modern OpenGL.

## Start learning

Read the [learning and research guide](docs/learning/README.md). It explains the
assignment and provides a staged route from rendering a triangle to animating the
complete body, with exercises, pseudocode, research links, and evaluation checks.

The chosen direction is **C11, GLFW, GLAD 2, and OpenGL 4.1 core**, targeting macOS
and Linux. You will implement the matrix maths and stack yourself.

## Current status

This repository currently contains the learning material. The application,
Makefile, shaders, and automated maths tests are exercises to implement; there is
no runnable program yet. Commands and interfaces in the guide describe the
intended implementation, unless explicitly identified as prerequisite checks.
